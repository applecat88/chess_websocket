Coin Rush

One browser window is one player. Each window holds a single WebSocket open to the server. The dark panel is the raw JSON on that socket: gold lines are yours, green lines came back from the server. Walk into the coin. The server is the only thing that may give you the point.

not connected
no players arrows or WASD
wire log sent 0 · received 0
join — you tell the server your name
welcome — server answers only you, with the whole room
joined / left — server tells everyone else
move — you tell the server where you walked
moved — server repeats that position to every socket
scored — server gives the point and places a new coin

The console variable socket is the live connection. Send socket.send(JSON.stringify({type:"scored", score:99})). The server answers with error. Your score does not change, because the browser does not get to invent one.
